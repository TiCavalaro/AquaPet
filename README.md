# AquaPet 🐠

Site institucional e catálogo da **AquaPet** — loja de aquarismo profissional em Araçatuba/SP.
Site **100% estático** (HTML + Tailwind + JavaScript), pronto para **GitHub Pages**, sem backend.

## ✨ Recursos
- Identidade visual premium "deep ocean" com animações sutis de água.
- **Mural de avisos** (atendimento, promoções, recados).
- **Calendário de atendimento** visual com horário semanal e dias especiais.
- **Catálogo** com busca, filtro por categoria, selos de promoção/popular e modal de produto.
- Totalmente responsivo (celular e computador).

## 🗂️ Estrutura
| Arquivo | Função |
|---|---|
| `index.html` | Estrutura e seções da página |
| `dados.js` | **Conteúdo editável** (produtos, avisos, calendário, contatos) |
| `app.js` | Motor que monta o site a partir do `dados.js` |
| `estilo.css` | Aparência e animações |
| `COMO-EDITAR.md` | **Guia passo a passo para atualizar o site sem programar** |

## 📝 Como atualizar o conteúdo
Quem mantém a loja edita **apenas o `dados.js`**. O passo a passo completo,
para quem não conhece programação, está em **[COMO-EDITAR.md](COMO-EDITAR.md)**.

## 💻 Rodar localmente
- No index.html, botão direito abrir com live server
